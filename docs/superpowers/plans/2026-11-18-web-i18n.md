# ATeam Web 中英双语支持实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** ATeam Web 界面全部产品文案支持 zh-CN / en-US 双语，可在设置页即时切换并持久化，默认跟随系统语言（对齐 NFR-I18N-001~009）。

**Architecture:** vue-i18n v11 Composition 模式（`globalInjection: true`），全量类型化 locale 文件（zh 文件以 `typeof enUS` 约束结构）；`setAppLocale()` 联动 vue-i18n、localStorage、`<html lang>`；Element Plus 经 `el-config-provider` 响应式跟随；轻量扫描脚本防硬编码文案。

**Tech Stack:** vue-i18n@11、Element Plus locale、TypeScript（moduleResolution: Bundler）。

**设计文档:** `docs/superpowers/specs/2026-11-18-web-i18n-design.md`

- [ ] **Step 4: 创建 i18n 实例**

创建 `apps/web/src/i18n/index.ts`：

```ts
import { createI18n } from 'vue-i18n'
import enUS from './locales/en-US'
import zhCN from './locales/zh-CN'

export type AppLocale = 'en-US' | 'zh-CN'

const STORAGE_KEY = 'ateam.locale'

// 语言解析顺序（NFR-I18N-003）：用户显式选择 > 系统语言（zh* → zh-CN）> en-US
function resolveInitialLocale(): AppLocale {
  const stored = localStorage.getItem(STORAGE_KEY)
  if (stored === 'en-US' || stored === 'zh-CN') {
    return stored
  }
  return navigator.language.toLowerCase().startsWith('zh') ? 'zh-CN' : 'en-US'
}

export const i18n = createI18n({
  legacy: false,
  globalInjection: true,
  locale: resolveInitialLocale(),
  fallbackLocale: 'en-US',
  missingWarn: true,
  fallbackWarn: true,
  messages: {
    'en-US': enUS,
    'zh-CN': zhCN,
  },
  datetimeFormats: {
    'en-US': {
      long: {
        year: 'numeric',
        month: 'short',
        day: 'numeric',
        hour: '2-digit',
        minute: '2-digit',
      },
    },
    'zh-CN': {
      long: {
        year: 'numeric',
        month: 'long',
        day: 'numeric',
        hour: '2-digit',
        minute: '2-digit',
        hour12: false,
      },
    },
  },
})

// 应用语言切换：更新 vue-i18n、持久化、同步 <html lang>（NFR-I18N-002）。
// Element Plus 的 locale 由 App.vue 的 el-config-provider 响应式跟随，无需在此处理。
export function setAppLocale(locale: AppLocale) {
  i18n.global.locale.value = locale
  localStorage.setItem(STORAGE_KEY, locale)
  document.documentElement.lang = locale === 'zh-CN' ? 'zh-CN' : 'en'
}

// 启动时按解析结果同步 <html lang>（index.html 静态默认为 en）
document.documentElement.lang = i18n.global.locale.value === 'zh-CN' ? 'zh-CN' : 'en'

export default i18n
```

import { computed } from 'vue'
import { useI18n } from 'vue-i18n'
import type { RunStatus, TaskStatus } from '@ateam/shared'

const props = withDefaults(
  defineProps<{
    status: TaskStatus | RunStatus
    kind?: 'task' | 'run'
  }>(),
  { kind: 'task' },
)

const { t } = useI18n()

type TagType = 'primary' | 'success' | 'info' | 'warning' | 'danger'

const label = computed(() => {
  if (props.kind === 'run') {
    return t(`common.status.run.${props.status}`)
  }
  return t(`common.status.task.${props.status}`)
})

const tagType = computed<TagType>(() => {
  const status = props.status
  if (status === 'done' || status === 'completed') {
    return 'success'
  }
  if (status === 'in_progress' || status === 'running') {
    return 'primary'
  }
  if (status === 'failed') {
    return 'danger'
  }
  if (status === 'blocked' || status === 'cancelled') {
    return 'warning'
  }
  return 'info'
})

### Task 9: 硬编码文案扫描脚本（NFR-I18N-001 轻量防护）

**Files:**
- Create: `apps/web/scripts/check-i18n.mjs`
- Modify: `apps/web/package.json`（scripts 增加 `check:i18n`）

- [ ] **Step 1: 编写扫描脚本**

创建 `apps/web/scripts/check-i18n.mjs`：

```js
#!/usr/bin/env node
// 扫描 Vue 模板中的硬编码可见文案（NFR-I18N-001 的轻量防护）。
// 规则（启发式）：
//   1. 文本节点中未被 {{ }} 插值包裹的字母/CJK 字符
//   2. title/placeholder/label/aria-label 等静态属性中的字面量文案
// 命中即以非零退出码失败。已知噪声（如纯 ASCII 符号、品牌名）由文件内
// 白名单注释控制，不设全局例外。
import { readFileSync, readdirSync } from 'node:fs'
import { join } from 'node:path'
import { fileURLToPath } from 'node:url'

const SRC_ROOT = fileURLToPath(new URL('../src', import.meta.url))
const TEXT_NODE = />([^<>{}]*[A-Za-z一-龥][^<>{}]*)</g
const STATIC_ATTR =
  /(?<![:@\-])\b(title|placeholder|label|aria-label)="([^"]*[A-Za-z一-龥][^"]*)"/g
// 白名单：品牌名、版本号片段、语言切换器的原生语言名（约定不翻译）
const ALLOWED_TEXT = ['ATeam', 'OK ·', 'v0.1.0', '简体中文', 'English']

function listVueFiles(dir, out = []) {
  for (const entry of readdirSync(dir, { withFileTypes: true })) {
    const full = join(dir, entry.name)
    if (entry.isDirectory()) {
      listVueFiles(full, out)
    } else if (entry.name.endsWith('.vue')) {
      out.push(full)
    }
  }
  return out
}

function stripInterpolations(template) {
  return template.replace(/{{[\s\S]*?}}/g, '')
}

function isAllowed(text) {
  return ALLOWED_TEXT.some((token) => text.includes(token))
}

const findings = []
for (const file of listVueFiles(SRC_ROOT)) {
  const content = readFileSync(file, 'utf8')
  const match = content.match(/<template[^>]*>([\s\S]*)<\/template>/)
  if (!match) {
    continue
  }
  const rel = file.slice(file.indexOf('src'))
  const lineAt = (index) => content.slice(0, index).split('\n').length

  const stripped = stripInterpolations(match[1])
  for (const m of stripped.matchAll(TEXT_NODE)) {
    const text = m[1].trim()
    if (text && !isAllowed(text)) {
      findings.push(`${rel}:${lineAt(m.index)} 文本节点疑似硬编码文案: "${text.slice(0, 60)}"`)
    }
  }
  for (const m of content.matchAll(STATIC_ATTR)) {
    // 静态属性命中即报告（动态绑定以 : 开头，不会被此规则命中）
    findings.push(
      `${rel}:${lineAt(m.index)} 静态属性 "${m[1]}" 疑似硬编码文案: "${m[2].slice(0, 60)}"`,
    )
  }
}

if (findings.length > 0) {
  console.error(`发现 ${findings.length} 处疑似硬编码文案：`)
  for (const finding of findings) {
    console.error(`  ${finding}`)
  }
  process.exit(1)
}
console.log('i18n 扫描通过：未发现硬编码文案')
```
